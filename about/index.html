How it is built

Design choices

Posts stay where they were posted

Every tile is the original Instagram or X post, shown with the platform's own embed. No copies of anyone's photos are stored here. If a post is deleted or embedding is switched off, it disappears from this site too.

Location first

Moving countries is hard right now, so every tile leads with where the person is: country, region, city. "Relocation friendly" when they are open to moving.

Fair, stable order

Each visitor gets their own random order, so nobody is always on top. It stays the same across visits (a seed kept in your browser only, never sent anywhere). New people slot in without reshuffling everyone else.

Deep links

The # in the corner of each tile copies a link that opens the page with that person first. Some profiles are not in the public list and are reachable only through a direct link.

Personal pages that grow

Anyone can have a page at /people/name/ with a bio that builds up over time. Tiles only show "Read more" when there is more to read.

Light on third parties

No tracking scripts. Embeds only load when they are about to scroll into view, and X embeds ask not to track visitors. Plain HTML, no build step, hosted on GitHub Pages.

Taken down the same day

Listed and want to be removed, or moved city? Email us and it is done the same day.

Open source

Everything, including the list of profiles, is public on GitHub. Pull requests welcome.
